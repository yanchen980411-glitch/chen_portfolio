# 参考图生成计划（历史 v1）

> 当前生效版本已改为正方体方案，详见 `docs/restoration-plan.md` 与 `references/locked/v1/`。本文件保留早期棱柱方案作为过程记录，不再作为构建基线。

## 已确认范围

- 站点：中文主导的单页个人作品集。
- Section：Hero、Selected Works、Contact；Selected Works 另含项目详情关键状态。
- 项目：AG1 AR 高尔夫眼镜、S50C 摄像头测距仪、Tools App。
- 来源：用户提供的简历与 15 张真实界面截图；Belen Jones 网站只作为布局、动效和交互基准。
- 公开边界：用户已确认三组项目名称与截图可以公开。
- 联系方式：网页主动作使用邮箱；电话默认不公开。

## STYLE_FINGERPRINT

- 画布：桌面参考比例 16:9；满屏 section，外边距约 16–24px。
- 基础色：墨黑 `#080A09`、暖灰白 `#F0EEE8`、柔和雾蓝 `#CCD4E7`。
- 项目色：AG1 `#CFF2C8` / `#00FF1A`；S50C `#CBDCE7` / `#19C8C4`；Tools App `#EEEAE2` / `#14B8C4`。
- Display：超宽、超粗、紧行距；当前项实心，非当前项 1px 轮廓。中文采用重黑字并适度横向拉宽，英文保持 extended grotesk 气质。
- Body/Label/Nav：等宽字体、全大写英文辅助标签；中文正文保持短句与较宽行距。
- Chrome：右上白色胶囊按钮、黑色粗体标签、柔和阴影；详情页左上 `/返回` 与 `下一个`。
- 几何：大面积直角画布与单一大圆角信息面板并存；不新增 bento、渐变字、无意义图标或装饰卡片。
- 材质：平涂背景、真实 UI 截图、黑色三维棱柱；不使用随机光晕、玻璃拟态或 AI 科技渐变。
- Signature motif：项目数据驱动的 N 边棱柱；每个项目对应一个侧面，当前三项目为三棱柱。
- 不可漂移：字体角色、胶囊按钮、实心/轮廓标题逻辑、三棱柱、真实项目截图、项目色映射。
- 允许变化：背景项目色、棱柱旋转角度、section 的标题位置与密度。

## 01 Hero — C0 code-only

- 职责：三秒内识别严琛、交互与用户体验设计师、智能硬件与配套应用方向。
- 可见内容：`严琛`、`交互与用户体验设计师`、一句定位、`作品`/`联系` 导航、向下提示。
- 个人证据：棱柱下方明确标记 `01 AG1 · 02 S50C · 03 TOOLS`，三项真实项目对应三个长侧面。
- 作者性动作：一只无纹理线框三棱柱在 Hero 中预告“三项目 / 三侧面”，滚动到作品区后被真实项目纹理填充。
- 主焦点：超大中文姓名；次焦点为右中线框三棱柱与左下定位文案。
- 阅读路径：姓名 -> 角色 -> 三面能力 -> 向下进入作品。
- 留白：右侧是棱柱旋转与响应式裁切 runway；底部留白用于进入下一 section 的动效交接。
- 代码负责：全部文字、项目映射图例、导航、按钮、线框 WebGL、滚动提示与动效。
- Raster：无 section 专属 raster；不使用头像。
- 响应式：移动端姓名缩小为两行，棱柱纵向居中，导航变成顶部四格细边框栏。
- 禁止融合：不得把姓名、角色、CTA 或证据文字烘进图片。

## 02 Selected Works — C2 independent-media + code WebGL

- 职责：三秒内看见三个真实智能硬件/应用项目，并理解中央棱柱的每个侧面就是一个项目。
- 可见内容：AG1、S50C、Tools App 项目名；中央三棱柱；项目色背景；`严琛`/`联系`；项目序号/类型；独立于项目截图的滚轮、拖动与进入提示。
- 个人证据：用户提供的三组真实界面截图。
- 作者性动作：项目数量直接决定几何侧面数，滚轮切换一面时标题实心状态、背景色和纹理同步变化。
- 主焦点：中央三棱柱；次焦点是当前实心项目名和右上导航。
- 阅读路径：当前项目名 -> 纹理面 -> 交互提示。
- 留白：右侧背景为空间平衡和旋转 runway，不添加无关内容。
- 代码负责：标题列表、项目序号/年份/类型、导航、背景、WebGL 几何、棱柱外部交互提示、滚轮/拖动/点击状态。
- 独立媒体：每个项目一张主纹理，来源分别为 `AG1 主要界面/主要操作界面.png`、`S50C 主要界面/单次测量.png`、`app 主要界面/首页—已连接.png`。
- Raster 预算：3 张真实截图；无生成项目视觉。
- 响应式：桌面保留左侧巨型标题；移动端隐藏大标题，保留顶部四格导航与中央纵向项目面，滚动逐项目切换。
- Exclusion zone：每个界面截图的完整 UI 边界不得被文字、线条或另一项目遮挡。
- 禁止融合：三个项目截图不能互相叠压；最终项目文字不得写进纹理。

## 03 Project Detail — C2 independent-media

- 职责：快速理解项目、个人角色、核心设计范围，并查看完整界面状态。
- 可见内容：`/返回`、`下一个`、项目标题、年份/类型、角色、项目说明、技能与界面画廊。
- 个人证据：简历中经确认的项目职责与对应真实截图。
- 作者性动作：左侧 60% 媒体随滚动切换，右侧 40% 项目信息保持粘性；项目色继续作为整页背景。
- 主焦点：左侧当前完整界面；次焦点为右侧项目标题与角色说明。
- 阅读路径：界面 -> 项目标题 -> 角色/说明 -> 下一张界面。
- 代码负责：全部文字、导航、两栏布局、粘性行为、媒体容器和滚动状态。
- 独立媒体：当前项目的 4–6 张真实截图；第一张不得放大到明显失真。
- 响应式：移动端先项目信息、后单列截图；`返回/严琛/联系/下一个` 固定为顶部四格栏。
- 禁止融合：项目说明不能烘进截图；不同界面之间不共享阴影或遮挡。

## 04 Contact — C0 code-only

- 职责：三秒内看见联系意图和唯一主动作——发送邮件；黑色联系面板必须成为第一焦点。
- 可见内容：`让复杂的工具，变得清晰。`、简短合作邀请、邮箱、`返回作品`。
- 个人证据：交互/UX 角色、智能硬件与配套应用方向、真实邮箱。
- 作者性动作：作品区的纹理棱柱在结尾退回线框并缓慢收束，表示把硬件、应用与系统汇成一条清晰体验。
- 主焦点：右侧近黑色圆角联系面板与白色“发送邮件”按钮；次焦点是左侧描边中文联系句；第三焦点是下方线框三棱柱。
- 阅读路径：联系面板 -> 发送邮件 -> 联系句 -> 三项目图例。
- 留白：左侧描边标题与右侧面板之间作为叙事停顿；下方三棱柱缩小并与面板保留明确安全间距。
- 代码负责：所有文字、邮箱链接、面板、导航、线框棱柱和动效。
- Raster：无 section 专属 raster。
- 响应式：移动端联系面板置于标题下方，不覆盖主句；“发送邮件”按钮全宽；线框棱柱在面板之后显示。
- 禁止融合：邮箱与个人信息不得写进任何背景图。
